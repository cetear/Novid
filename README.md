## 文档维护

`docs/` 根目录维护长期说明、规范与可复用配置示例；以后临时或带时效性的资料统一放 `docs/temp/`。同类内容优先更新已有文档，稳定的功能和配置同步更新长期说明。新增或移动文档时维护索引与引用路径。环境凭证、业务资料、运行日志和本地产物继续保持 Git 忽略。

开发按用户指定的范围与阶段推进，更新实际验证结论和交接；阶段记录不能作为未实现接口的使用依据。
