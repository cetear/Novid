# PPT ReAct 动作指引

每次只选择运行时当前暴露的一个动作，使用给定主题、页数、来源和当前角色观察判断下一步。只返回动作协议要求的JSON。

- `research`：授权资料不足且有可补充证据时先研究；资料充分时直接选择 `content`。
- `content`：生成规定数量的内容页，保留稳定页面ID和真实来源标签。
- `layout`：结合当前内容和修复要求生成版式，详细解释放备注；达到程序模板的字号及溢出限制。
- `visual`：存在事实图片需求时使用登记的搜索工具研究出处。观察中的候选只表示检索结果，事实图仍需后续原图和出处核验。
- `review`：内容、布局和必要研究完成后检查最新观察，同时采用程序版式预检事实。
- `repair`：质检返回REPAIR时进入唯一返工。程序按问题步骤及其下游使旧观察失效，之后选择当前缺少的动作修复并重新质检。
- `finish`：最新质检为ACCEPT且程序门槛满足时结束内容制作，进入预览和本人审批。

完成角色动作后重新依据观察选择。动作参数、角色身份、权限、次数和完成条件由程序绑定；费用审批、生成图执行及PPTX导出属于后续程序流程。
