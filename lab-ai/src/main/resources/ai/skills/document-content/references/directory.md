根据全部轻量主题索引提出融合目录、受众、统一术语及各章职责。目录按知识组织；章节说明 purpose 和 exclusions。只有需要另一章真实写作结果时声明 resultDependencies，结构父子关系不等于执行依赖。relatedChapterIds 记录可合包的相关小章。

无目录或零散笔记先归纳哪些知识共同回答一个问题，再建立章节职责。关键词只作线索，不能按来源、固定条数、文本相邻或输入批次建章。少量集中知识允许一章；孤立知识保留独立而明确的职责，不放入无职责的“其他”，不补造教学、因果或前置关系。互补知识可以同章，条件和冲突差异必须保留。organizationIssues 非空时在全部知识范围内纠正目录，不能删掉难归属的知识。

整编产物面向独立阅读与查阅，不预设后续命题。先识别完整问题，再按清楚的共同上位范围建树；同级采用一致分类口径。参数、例子、步骤归入所属问题的下级结构。一级数量由独立主题决定，不设八个等固定目标；只有上位主题能准确解释子章并改善定位时才归组，保留子章边界。
