# 数据库访问规范

## 长期技术标准

生产数据库访问按以下顺序选择：

1. MyBatis-Plus：单表 CRUD、计数和简单条件更新。
2. MyBatis：联表、动态权限过滤、数据库函数、显式行锁、批量写入和条件更新等定制 SQL。
3. 原生 JDBC：只有前两者无法满足需求时使用，并在代码附近说明具体原因。

数据库实现放在 `lab-data` 内。业务与 Web 模块依赖契约端口，不接触 Mapper、PO、SQL 或 Wrapper。SQL 参数使用 MyBatis 绑定；动态列名使用固定分支，禁止拼接外部输入。

MyBatis-Plus Mapper 依赖通过 Spring 构造器注入，确保 MapperFactoryBean 完成注册后再使用。不要在仓库构造期间直接从 SqlSessionTemplate 获取尚未注册的 Mapper。

## 现有实现

账户、令牌和知识库的常规操作使用 MyBatis-Plus `BaseMapper` 与 Wrapper。其余仓库中的业务 JDBC SQL 已迁入按仓库组织的 Mapper 接口和 XML，保留原事务注解、行锁顺序、版本条件、执行代次、受影响行数检查及数据库时间函数。

复杂投影使用内部 `SqlRow` 和 MyBatis `SqlRowTypeHandler`，保留 NULL、列顺序及驱动的时间转换行为。该类型处理器由 MyBatis 调用，不独立执行数据库 SQL。MyBatis 一级缓存设为 `STATEMENT`，事务中重复读取锁定状态仍访问数据库。

启动版本检查保留 JDBC 元数据接口，用于建立 Mapper 之前确认 MySQL 版本；模式迁移继续交给 Flyway。验收脚本中的直接 SQL 用于准备、核对和清理合成测试夹具，已移至 `scripts/validation/ValidationSql.java`，生产 `SqlSupport` 不再暴露 JDBC。

## 授权与事务边界

锁顺序为 `system_control → users → 当前任务／资源`。知识修改、处理激活、撤权和治理仍取得排他知识闸门，必须在用户／资源锁之前取得，不允许共享锁升级。普通写入使用共享闸门和当前用户排他行锁，保留本人去重／配额串行化；文档查询与执行权核验使用共享闸门和共享用户行锁，续租、预算及检查点再锁当前任务／入库行。不同用户及任务不共用排他全局锁，权限版本、角色、enabled和强制改密状态仍按当前数据库事实核验。

学习计划接受与入库结构保存先在事务外完成正文／分片哈希、检查点证明、规则验证和JSON编码，再通过有界事务提交。提交再次检查来源权限、正文版本／解析代次、租约和fencing；计划还复核持久摘要、检查点摘要及剩余预算。结构在事务外按最多256行及512KiB保守负载估算分批，单行超过估算阈值仍独立发送；结构与完整标记原子提交，失败整体回滚。

领取仅处理当前候选，维护由独立定时入口分批提交，每类最多16个ID。维护UPDATE绑定选定ID并保留状态条件；维护与领取使用READ_COMMITTED、共享闸门和行级SKIP LOCKED。领取排除超出累计期限的任务和仍有SENDING意图的入库代次，维护延迟不会赋予其重发权。

MyBatis默认语句期限5秒，Spring默认事务10秒，续租／队列3秒，普通准备后提交5秒。入库结构保存单独经SqlSupport.writeIngestionStructure提交，整个事务期限30秒，以容纳多个有界批次；单条语句仍限5秒，事务剩余期限会进一步约束语句。结构事务期间持有共享授权锁及当前入库行锁，可能短暂阻塞撤权和同入库续租；180秒租约不因此延长。新连接初始化InnoDB锁等待3秒，驱动连接建立5秒、网络读取15秒。仅在事务代理外对续租的取连接失败、明确锁竞争或已回滚的语句期限做有限恢复；不自动重放正文、预算、模型或不确定提交。

## 历史改造与验证

慢 SQL 由数据模块的 `SlowSqlInterceptor` 在 `StatementHandler.query/update` 层登记，覆盖 MyBatis XML 和 MyBatis-Plus 生成语句。默认达到 1000ms 时登记成功或失败调用，不改变原 SQL、返回值、异常、事务及超时。耗时包含 JDBC 执行、网络／锁等待和查询结果读取／映射，不包含连接池取连接、语句准备／绑定及事务提交；不能等同 MySQL 服务器执行时间。批量多行 SQL 可以覆盖，JDBC BATCH 实际执行、游标消费及 Flyway 不在当前范围。

专用文件保存 Mapper 标识、操作类型、耗时、结果、脱敏异常类型、脱敏模板哈希和已有请求／任务关联字段。不读取绑定参数或结果正文；SQL 字符串／数字字面量及注释被移除，不确定语法整条省略，仅保留 statementId 及其哈希。模板展示默认最多 4096 字符，截断不影响完整脱敏模板的哈希。配置、归档及排查见[日志记录与问题排查](日志记录与问题排查.md)。
