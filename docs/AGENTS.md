# 文档维护约定

- `docs/` 根目录维护长期文档：项目介绍、接口、部署、使用指南、开发规范及可复用配置示例。同类内容更新已有文档。
- `docs/temp/` 统一存放改造方案、架构评估、开发阶段交接、变更记录、测试／验收报告和其他临时或带时效性的资料。
- 新建或移动文档时，同步维护 `docs/README.md`、`docs/temp/README.md` 和引用路径；从临时记录中提炼出的现行规则归入对应长期文档。
- `temp` 资料按记录时点理解；当前行为以长期文档和实际代码为准。保留历史证据及其验证限制。
- 私有凭证文件继续保持 Git 忽略；运行日志、测试产物及业务数据放在已有的本地忽略目录中。
